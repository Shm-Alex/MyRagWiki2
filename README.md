# MyRagWiki

Локальный RAG-движок для построения персональной базы знаний на .NET 9.

---

## О проекте

**MyRagWiki** — консольное приложение, реализующее архитектуру **RAG (Retrieval-Augmented Generation)**. Движок загружает неструктурированные документы (PDF, DOCX, HTML, Markdown, TXT), разбивает их на смысловые блоки, индексирует через локальные LLM-модели и отвечает на вопросы строго на основе фактов из базы знаний — без галлюцинаций и без отправки данных в облако.

Проект создан в рамках инициативы **Career CoPilot** — персонального ИИ-ассистента для управления карьерой и подготовки к собеседованиям.

---

## Возможности

- **DDD-архитектура** — чёткое разделение на слои Domain, Application, Infrastructure, Presentation
- **Универсальный парсинг** — поддержка PDF, DOCX, HTML, Markdown, TXT
- **Умный чанкинг** — разбиение текста по смысловым заголовкам (`##`, `<h1>`), а не по символам
- **Файловое кэширование** — SHA-256 хэширование исключает повторный парсинг
- **Семантический поиск** — векторизация через `nomic-embed-text`, поиск по косинусному сходству (Top-K)
- **Локальный ИИ** — интеграция с Ollama (`qwen2.5-coder:14b`)
- **Приватность** — 100% локальная работа, данные не покидают компьютер

## Быстрый старт

### 1. Требования

- [.NET 9 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- [Ollama](https://ollama.com/) (установлен и запущен)

### 2. Установка моделей

```bash
ollama pull nomic-embed-text
ollama pull qwen2.5-coder:14b
```

### 3. Сборка и запуск

```bash
git clone https://github.com/Shm-Alex/MyRagWiki.git
cd MyRagWiki/src/MyRagWiki
dotnet restore
dotnet build
dotnet run
```

### 4. Настройка

В файле `Presentation/Program.cs` укажите путь к папке с документами:

```csharp
var docsFolder = @"C:\Users\YOUR_NAME\Documents\Obsidian Vault\00_Raw_Data";
```

## Использование

После запуска программа:
1. Сканирует указанную папку и парсит все документы
2. Векторизует чанки через `nomic-embed-text`
3. Запрашивает у вас вопрос
4. Находит Top-3 релевантных фрагмента
5. Генерирует ответ через `qwen2.5-coder:14b`

Пример запроса:
```
Расскажи про мой опыт с Kafka и миграцией баз данных
```

## Чему я научился

1. **RAG — это инженерия, а не магия.** 80% успеха зависит от качества парсинга и чанкинга, а не от модели.
2. **Локальные модели требуют дисциплины.** Маленькие модели (4B) галлюцинируют, средние (14B) с жёсткими промптами работают надёжно.
3. **Контекстное окно — ограниченный ресурс.** Скармливать LLM всё подряд нельзя. Умный Retrieval критически важен.
4. **Ollama API прост и эффективен.** Три эндпоинта (`/api/tags`, `/api/embed`, `/api/generate`) закрывают 90% задач.
